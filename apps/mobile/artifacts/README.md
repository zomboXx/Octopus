# APK tùy chọn

Tải APK từ [GitHub Releases](https://github.com/zomboXx/Octopus/releases/tag/v0.6.3-ae.1).
Để website Docker phục vụ APK ngay trên máy, đặt file tại đây với tên
`octopus-android-debug.apk`. Nếu chưa có file, website dùng liên kết GitHub Releases.
Gói source không kèm APK; có thể tự build theo [hướng dẫn Android](../README.md).
